# Things That Should Not Exist

> A collection of solutions to problems nobody had, implemented with an unreasonable amount of logic, effort, and enthusiasm.

## What is this?

This repository exists because sometimes the simplest solution is just not interesting enough.

Why use `+` when you can implement binary addition from scratch?

Why use an existing algorithm when you can spend an afternoon rediscovering it?

Why write 5 lines when 50 lines can achieve the exact same result?

**Things That Should Not Exist** is a collection of unnecessarily complicated programming experiments, questionable engineering decisions, and logically sound implementations that have absolutely no business existing.

## Philosophy

- If it works, it doesn't mean it should exist.
- If it can be done the easy way, explore the hard way.
- Curiosity is a perfectly valid reason to write code.
- Performance is someone else's problem.
- Having fun is the entire point.

## Engineering Standards

- Must work (eventually).
- Must make logical sense.
- Must be unnecessarily complicated.
- Must not solve an actual business problem.
- Refactoring for simplicity is strongly discouraged.

## Disclaimer

None of the code in this repository should be used in production.

Not because it necessarily doesn't work.

But because we have collectively agreed that some things are better left unexplained.
